## Running Instruction

### `python`

To run the python file you are expected to provide 1 command argument which should be the wanted size of the dataset.\
The possible datasets size are:
- 1000
- 10000
- 20000
- 50000
- 100000
- 125000
- 250000
- 1000000
- 4000000

Example of command:

```bash
python merge_sort.py 1000
```
